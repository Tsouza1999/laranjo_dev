# laranjo.dev

Rodar localmente:

    npm install
    npm run dev

Build de produção: `npm run build` (saída em `dist/`).

Onde editar:
- `src/data.js`: todas as frases, desculpas, itens do bingo, regras e desvios.
- `src/styles.css`: cores nas variáveis `:root`.
- `src/tabs/`: uma aba por arquivo; registre novas abas em `src/App.jsx`.
- `src/components/`: peças reutilizáveis (Button, Tabs, BingoBoard etc.).
